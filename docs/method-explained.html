零标签怎么分开黑白：自监督异常检测方案

全程不使用任何欺诈标签。核心思想一句话：只用正常用户的行为数据训练一个"预测行为"的模型，它学会正常规律后，谁让它频繁预测失败（惊讶），谁就异常。本页每个例子都来自真实实验数据。

训练标签从哪来？序列的下一个事件本身就是标准答案——"看了前 10 个操作，猜第 11 个是什么"，猜完对答案，答案就在数据里。这就是"自监督"：有监督信号，但不需要人工标注，更不需要知道欺诈长什么样。训练数据直接用 unlabeled 用户当白样本——实测混入 10% 欺诈都无损（欺诈模式在训练信号中占比 ~1%，模型来不及把它学成"正常"）。

STEP ①

编码：行为事件 → 向量

统一 Schema，8 路字段各查各的 Embedding 表再拼接
真实例子 · 来自用户提供的样本数据 N00010

原始事件：{"type":"消费", "t":"2024-06-03 08:36:00", "amount":167313}

事件类型消费 → ID 9
result无此字段 → 0(不适用)
channel/ip缺失 → 0
全局金额桶167,313 > 全体p86分位 → 桶7
个人金额桶÷本人中位66,285=2.5倍 → 桶5
间隔桶距上一事件9分钟 → 桶2(5-30m)
时刻8.6时 → sin/cos

8 个索引各查各的 Embedding 表（类型表 12×32、个人金额表 8×16……），拼接成 96 维，线性投影到 64 维——这就是一个事件进模型的样子。整条序列 = [事件数 × 64] 的矩阵。

两个关键设计：

  • 缺失填"不适用"桶：登录没有金额、消费没有 result——统一 Schema 让字段不同的事件进同一条序列，缺的查 0 号可学习向量（不是数字零）；
  • 个人金额桶是全方案性价比最高的特征：同样是"转出 5 万"，对基线 500 的人是 100 倍（桶 7 顶格），对基线 5 万的人是 1 倍（桶 3 平常）——"个人基线"直接编进输入。实证：真实卡数据上加它 +3.8pp，逐笔定位 +19pp。
STEP ②

训练：只用白样本做"预测题"

按数据形状选三种出题方式——这是几十个实验裁决出的对照表
数据形状出题方式为什么实证
操作流（App日志）自回归+时间偏置：只看历史，预测下一事件的[类型/间隔/结果/个人金额档]盗号是因果链，"下一步"可预测；只看历史让攻击起点成为最大惊讶0.984
资金流（转账）整事件遮罩：随机遮15%事件用前后文猜回异常是账户整体风格，双向上下文即可0.904
消费流（卡交易）字段级遮罩：只遮金额、类别可见，学 P(金额|类别,时段)下一笔买什么本质随机；欺诈签名在"字段搭配不对"0.886
真实例子 · 自回归出题（操作流）

已见：[登录·成功·08:00] → [查余额·+27m] → [消费·167,313·+9m]
请预测第 4 个事件的：类型？间隔档？结果？个人金额档？
（标准答案在数据里：[消费·128,780·+29m]——猜错多少，参数就更新多少）

真实例子 · 字段级遮罩（消费流）

已见：[类别=grocery_pos, 时刻=23:40, 间隔=2h, 金额=???]
请预测被遮的金额档。正常用户深夜杂货店消费是小额 → 若真实金额是本人基线 12 倍 → 模型大吃一惊。

这个改动在真实卡数据上把 AUC 从 0.557（整事件遮罩，失败）救到 0.886——出题方式必须匹配数据形状，没有万能题型。

为什么自回归在操作流上赢完形填空（0.974 vs 0.926）：完形填空能看到被遮位置的"后文"，语境泄漏会把惊讶抹平；自回归严格只看历史——连续失败登录突然出现时，模型毫无准备，惊讶最大化。附带好处：打分单趟完成，推理成本只有遮罩法的 1/7。
STEP ③

打分三步：惊讶度 → 归一化 → 池化

全方案技术含量最高的部分，顺序和取舍都是拿失败换来的

第 1 步 · 逐位置算惊讶度（交叉熵）

真实例子 · 同一个模型在两种局面下的真实输出

正常局面——白样本会话中，真实事件是消费：

消费
27.2% ✓ 第一预测命中
登录
25.5%
查余额
18.2%

异常局面——黑样本爆发链中（前 149 秒是改密码），真实事件是改限额：

消费
28.9%
登录
25.5%
改限额
1.25% ← 真实事件，惊讶！

模型以为小间隔上下文里该是购物会话，真实答案只被给了 1.25% 的概率 → 交叉熵高 → 这个位置"可疑"。

第 2 步 · 难度归一化（z-norm）

不做这一步，分数方向是反的（实测 AUC 0.32）。黑样本的爆发窗口全是小间隔——形态像购物会话，本来就"好猜"；白样本孤立敏感事件间隔几小时到几天，本来就"难猜"。直接平均会得出"黑样本更正常"的荒谬结论。

真实例子 · 白样本训练集各间隔桶的期望惊讶度（实测统计值）
间隔桶≤1m1-5m5-30m0.5-1h1-6h6-24h
正常CE均值 μ1.711.711.722.232.312.34

z = (该位置CE − 同间隔桶的μ) ÷ 同桶σ

例：≤1m 桶里 CE=4.8 → z≈+4.6（比同难度正常位置惊讶 4.6 个标准差，高度可疑）；0.5-1h 桶里 CE=2.4 → z≈+0.2（那个难度下这很正常）。z 分回答的不是"惊讶多少"，而是"比同等难度下的正常人多惊讶多少"。这一步把 0.32 反转到 0.76。

第 3 步 · 池化：一串 z 分 → 一个风险分

规则：异常是局部的用 top-k，异常是整体的用平均（盗号只污染序列一小段 → top-5；钓鱼账户每笔都是作案 → 全序列平均，实测 0.904 > top-k 的 0.875）。

真实例子 · 两个真实用户的 top-5
z 分最高的 5 个位置top-5均值判定(阈值3.52)
黑 B_02914.65(解绑卡) 4.13(绑卡) 3.98(改限额) 3.81(借款) 3.70(借款)4.05命中 ⚑
白 W_04853.73(借款) 2.02(解绑卡) 1.72(绑卡) 1.69(绑卡) 1.42(设备变更)2.12放行

注意白样本也有一个 3.73 的单点高分（会话里巧合夹了笔借款）——这就是取 top-5 平均而非 top-1 的原因：单个巧合拉不动分数，成串的异常才能过线。而黑样本的 top-5 里 3 个直接落在爆发链上——这 5 个位置同时就是给审核员的"可疑操作清单"。

STEP ④

融合通道：模型原理上吃不到的信号怎么补

一条用真金白银换来的机制规律

有一类信号永远不会以"惊讶"的形式冒出来：账户级的静态比例特征。例如"首次对手方占比"——模型学会"钓鱼账户的打款方就是全是生面孔"之后，预测得很准、CE 很低，信号在预测通道里消失了。

真实例子 · 以太坊钓鱼(全真实数据)的三组数字
做法AUC低误报召回 R@FPR1%
MEM 异常分（单独）0.903514.7%
"首次对手方占比"裸特征（单独）0.8168—
把该特征塞进模型当字段+预测头 ✗0.9041（无效）—
两个分数秩融合（0.6/0.4 加权）✓0.928144.9%（×3）

同一个信号，进预测通道无效，走融合通道立涨 2.5pp、低误报召回翻三倍，离全标签上限(0.934)只剩 0.006。

规律入册：判别信号分两类——模式类（序列/字段组合异常）进 masked/AR 预测通道；聚合类（比例、计数、静态画像）走分数级融合通道。对接真实业务："收款账号是否首次出现"是必采字段，以裸特征+融合方式使用。
STEP ⑤

阈值与输出：分数怎么变成决策

阈值不是拍的，是白样本分位数定的
真实例子 · temporal 实验的这一刀

取一批白样本分数的 99 分位 = 3.52 当阈值 → 数学上保证只误伤 1% 正常用户。这一刀实测能抓住 70.8% 的黑样本。B_0291(4.05) 超线命中、W_0485(2.12) 放行。想抓更多就把刀左移，用误报换召回——和评分卡运营完全一致。

  • 按活跃度分桶各定各的阈值（活跃用户与低频用户分数分布不同，一刀切会系统性误伤一群人），每月用新白样本重算防漂移；
  • 输出 = 风险分 + top-k 可疑位置（出证材料），进人工审核队列，不自动处置；
  • 审核结论回流成标签 → 攒到 10~50 个时用于融合权重与阈值校准，50+ 时启动监督模型接管（那是另一层的事，零标签方案本身是完全体）。
收官

为什么零标签能分开：原理 + 全部证据

不是运气，是原理保证 + 六个数据集的定量兑现

原理：方法从不试图认识"欺诈长什么样"（那需要标签），只认识"这个人群 + 这个人正常长什么样"。欺诈者可以伪装很多东西，但要同时做到"操作节奏像正常人、金额符合受害者本人惯例、对手方有历史、结果字段干净"几乎不可能——他没法表现得像受害者本人。

★ 两处"零标签超过全标签"的原因：个人基线、对手方新旧这些信息维度是标签模型（用统计特征的 LR）没有的——好的表示可以比标签更值钱。

唯一的前提（也是唯一的风险）：判别信号必须真的存在于行为数据里。PaySim 是反例——全标签模型也只有 0.61，数据本身无信号，任何方法都救不了。所以接入新数据的第一步永远是摸底（profile），确认信号在哪一层、有多强，再谈建模。
