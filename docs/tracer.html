一个账户进入系统后发生了什么

选一个真实账户，看它走完七站的完整记录。核心玩法：点击站点③的任意格子——每个格子是一个真实事件，点开能看到它的原始记录、编码桶号、模型对它的惊讶度和 z 分。旗标 ⚑ 是模型指认的三大可疑位置。

站点 ①②

原始序列 × 编码对照

每行一个事件：左边是原始记录，右边是编码后喂给模型的桶号。点行可联动下方热力条。
站点 ③④

模型逐位置审问：惊讶度热力条

一格 = 一个事件。颜色 = 归一化后的 z 分（红=比同难度正常位置惊讶得多，绿=平静）。⚑ = 全序列 z 分前三。点格子看该位置完整档案 ↓
z ≥ 3 高度可疑 1.5 ≤ z < 3 0.5 ≤ z < 1.5 −0.5~0.5 正常 z < −0.5 比正常还平静

站点 ⑤

池化：一串 z 分 → 一个风险分

站点 ⑥

阈值判定

阈值 = 白样本分数的 99 分位（误报率 1%），训练时算好存在模型文件里。
站点 ⑦

定位：给审核员的证据清单

z 分最高的三个位置回查原始事件——点击行可跳转到该位置的档案。
