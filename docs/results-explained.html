这些数字到底什么意思？

这一页只回答两个问题：① AUC 那些 0.x 的数字，翻译成人话是什么；② 为什么每个实验都要和"用了标签的有监督模型"比一下。所有图里的点都是真实实验算出的分数，不是示意。

体会到的规律就是反欺诈运营的本质：刀往左移多抓坏人但多误伤好人，往右移反之——不存在两全的刀位，只存在业务能接受的权衡。实验里通报的 "R@FPR1%=70.8%" 就是"刀定在误报 1% 的位置时能抓住 70.8% 的黑样本"。（注：这批测试黑白比是 5:1，为实验方便；真实场景白样本占绝对多数，同样的误报率意味着更大的误伤数量，所以刀通常定得很严。）

03

AUC：一个数字概括"两团分得多开"

定义：随机抽一个黑、一个白，黑的分数更高的概率

刚才你拖滑块时会发现：两团分得越开，随便怎么切都好切；越重叠，怎么切都难受。AUC 就是把"分得多开"压缩成一个数，它不依赖你选哪个刀位。三档真实对比（同一批用户、三种打分方式）：

❌ 随机乱打分（对照组）AUC = 0.47
两团完全叠死——随机抽一黑一白，黑分更高的概率 ≈ 抛硬币。切哪都一样烂。
⚠️ 打分方式不当（z-norm 后直接平均）AUC = 0.756
开始错开但重叠很大——能用来排序，单独定案会大量误判。
✅ 正确打分（z-norm + top-5）AUC = 0.959
基本分开，重叠只剩尾部——96% 的黑白配对里黑分更高。这就是"效果好"长的样子。

速查表：AUC 0.5=抛硬币；0.6=聊胜于无；0.7=能辅助排序；0.8=可用；0.9+=优秀；1.0=完美分开。我们各数据集的成绩：以太坊 0.904、Sparkov 0.886、temporal 0.959 属于"优秀"档，PaySim 0.561 属于"≈抛硬币"档。

04

为什么要和"有监督"比：它是量数据的尺子

开卷考试 vs 闭卷考试

把每份数据看成一张考卷：

  • 有监督 oracle = 开卷考生——它拿着全部答案（黑白标签）学习，考出来的分数逼近这份数据的理论上限：数据里总共有多少可分的信号，它基本能全捞走；
  • 我们的 MEM = 闭卷考生——从没见过一个黑标签，全靠自己学"正常长什么样"。

所以对比的意义是：MEM 的绝对分数说明不了任何事，"闭卷离开卷差几分"才说明方法的好坏；开卷本身考砸了，则说明卷子（数据）没货。六个数据集的对比：

照着"看差距不看绝对值"的读法，六行各是什么结论：

数据读法
temporal / Ethereum / TabFormer闭卷贴着开卷（差 0.03~0.07）——方法把数据里有的信号几乎全榨出来了，绝对分的高低是数据信号强弱决定的
Sparkov ★闭卷反超开卷——因为我们给 MEM 加了"个人金额基线"字段，这是 oracle 的统计特征里没有的信息维度
BankSim差距偏大（0.16）——训练数据欺诈污染率 19%，超出验证过的 10% 上限，是已知边界的实证
PaySim开卷考生也只有 0.61 → 卷子本身没货（欺诈是随机注入的，行为里没有信号）。这 0.561 不是方法的失败，是这份数据被判"不值得用"的证据

这个对比对你还有一个实用价值：拿到北部湾数据后，先花半天跑个开卷 oracle，就能预测闭卷 MEM 大概能考多少（oracle 减 0.03~0.07）——不用训模型就知道这份数据值不值得做、能做到什么程度。
